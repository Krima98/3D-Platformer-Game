## 3D Platformer game
A 3D platformer game developed in Unity as my Bachelor's degree project in Multimedieteknologi og design at the University of Agder (UiA), 2026.

### Technical Details
* **Game Engine:** Unity
* **Programming Language:** C#
* **3D Modeling:** Blender
* **Textures:** Adobe Photoshop, Blender
  
### Download project file
* **Unity hub editor version:** 6000.3.8f1

*Notes: Once project is open, it may look empty! Go to "A - Scenes" and select MainMenu. Some materials will appre blue for some seconds at first.* 

### Download the Game
You can download the game directly without Unity installed.
1. Go to the **Releases** section on the right side of the repository.
2. Download the latest `.zip` file.
3. Extract and run the game.

*Notes: There will be no music and missing sounds due to copyright for sharing this project*
