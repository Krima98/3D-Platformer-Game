## 3D Platformer game
*3D platformer game developed in Unity as my Bachelor's degree project in Multimedieteknologi og design at the University of Agder (UiA), 2026.*

**Developed as a solo project**, the goal of this project was to combine various subjects I studied throughout my degree and apply them to a new field. Specifically, the project combined knowledge from programming and 3D modeling to develop a game using a game engine. This involved researching and evaluating which game engine best suited the project's needs, and then learning the relevant programming language.

The game itself was inspired by the movement and feel of 3D Mario titles. The core gameplay loop draws inspiration from TrackMania, focusing on high replayability through time-trial mechanics. The primary objective is to finish maps as fast as possible using a built-in timer, encouraging players to optimize their movement, discover shortcuts, and beat their own highscores.

--- 
### Technical Details
* **Game Engine:** Unity
* **Programming Language:** C#
* **3D Modeling:** Blender
* **Textures:** Adobe Photoshop, Blender

### Game functionality 
1.  Custom movement system built with Unity's Character Controller and tailored physics.
2.  Two playable levels.
3.  Two cosmetic/skins unlocks for playable character.
4.  Save/load system for game progress using JSON data.
5.  Keyboard/mouse and gamepad support (Gamepad is supported for gameplay, with menu navigation optimized for keyboard/mouse).
6.  Audio and sensitivity settings (Note: Music is excluded in public releases due to copyright).
7.  Fully functional pause menu.
8.  Option to disable spinning obstacles in the pause menu (accessibility feature to make specific sections more approachable).

### What I learned
* Unity game engine.
* C# for game development.
* Typical programming patterns like: Observer pattern, Singleton, and State-machine.
* Implementing a save/load system for game progress.
* Visual game effects with shader and particle system.

> **Note:**
